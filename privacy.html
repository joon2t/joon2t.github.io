whylabworks 개인정보처리방침

시행일: 2026년 11월 7일

1. 수집하는 정보

이 앱은 운영자 본인이 구글 로그인으로 허용한 범위 안에서만 YouTube 계정에 접근합니다.

  • 영상 업로드와 영상 정보(제목·설명·공개 설정) 관리
  • 본인 채널의 조회수·시청 시간 등 통계 조회

2. 이용 목적

본인 채널에 영상을 올리고 성과를 확인하는 데만 씁니다. 광고, 판매, 프로필 분석에는 쓰지 않습니다.

3. 보관과 공유

로그인 토큰과 조회한 통계는 운영자 본인 컴퓨터에만 저장하며, 제3자에게 제공하거나 판매하지 않습니다.

이 앱이 Google API에서 받은 정보의 사용과 전송은 Google API 서비스 사용자 데이터 정책(제한적 사용 요건 포함)을 따릅니다.

이 앱은 YouTube API 서비스를 사용합니다. YouTube 서비스 약관과 Google 개인정보처리방침이 함께 적용됩니다.

4. 접근 권한 철회

myaccount.google.com/permissions에서 언제든 이 앱의 접근 권한을 해제할 수 있습니다. 해제하면 저장된 토큰은 더 이상 쓸 수 없습니다.
